# Gestao_Receitas_Culinarias

Projeto academico para gestao de receitas culinarias. O frontend esta em Angular e o backend sera implantado futuramente em **Java + Spring Boot**.

## Estrutura do repositorio

| Pasta | Conteudo |
| --- | --- |
| `frontend/` | Aplicacao Angular (interface e navegacao) |
| `backend/` | Futuro backend Java + Spring Boot (ainda nao implementado) |

## Stack (resumo)

| Camada | Tecnologia |
| --- | --- |
| Frontend | Angular 17 + TypeScript |
| Backend (futuro) | Java + Spring Boot |

## Como rodar do inicio

1. Instale o **Node.js LTS** e o **npm**.
2. No terminal, entre na pasta do frontend:

```
cd frontend
npm install
```

3. Inicie o servidor de desenvolvimento:

```
npm start
```

4. Acesse `http://localhost:4200` no navegador.
